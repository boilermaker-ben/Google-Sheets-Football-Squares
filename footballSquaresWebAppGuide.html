Steps to create a player picker link:
1 Open Apps Script
In the Google Sheets top menu, click:
Extensions  ›  Apps Script
2 Start Deployment
In the upper-right corner of the editor, click:
Deploy
Then select New deployment.
3 Choose Type
Click the gear icon ⚙️ (Select type) on the left and choose Web app.
4 Configure Settings
Description (optional/anything)
NFL Squares
Web app
Execute as MUST BE
Me (you@gmail.com)
The web app will be authorized to run using your account data.
Who has access MUST BE
Anyone
Allows players to choose squares without needing a Google account.
5 Deploy & Copy URL
Click
Deploy
(grant permissions if prompted), then click:
Copy
to copy your Web App URL. Refresh this page to add a menu item to open/copy the "Form" you've created.
